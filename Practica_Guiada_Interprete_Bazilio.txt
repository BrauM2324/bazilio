Bazilio es un lenguaje de programación para componer música. Tu intérprete será un doble intérprete: ejecuta el programa (sentido informático) y además interpreta una pieza (sentido musical), generando la partitura y el audio. Lo construirás en seis etapas; al terminar cada una tendrás algo que funciona y que puedes comprobar con una salida concreta.

Etapa 1. Lexer y parser: reconocer el lenguaje
Objetivo: que tu programa distinga un programa Bazilio válido de uno inválido, antes de ejecutar nada. Aquí solo hay análisis; no se ejecuta ninguna instrucción.

Paso 1.2  Escribe las reglas del lexer
El lexer convierte el texto en tokens. En un archivo Bazilio.g4 empieza con la declaración grammar Bazilio; y agrega estas reglas al final del archivo:
Bazilio.g4 (parte del lexer)
/* ---------- Símbolos ---------- */
INICIO : '|:' ;
FIN    : ':|' ;
ASIGNA : '<-' ;
LEE    : '<?>' ;
ESCRIBE: '<w>' ;
TOCA   : '(:)' | '<:>' ;      // el enunciado usa las dos escrituras
AGREGA : '<<' ;
CORTA  : '8<' ;
LONG   : '#' ;
 
MAS : '+' ;  MENOS : '-' ;  POR : '*' ;  ENTRE : '/' ;  MODULO : '%' ;
IGUAL : '=' ;  DISTINTO : '/=' ;
MENOR : '<' ;  MAYOR : '>' ;  MENORIGUAL : '<=' ;  MAYORIGUAL : '>=' ;
 
/* ---------- Palabras reservadas (antes que VAR) ---------- */
SI      : 'if' ;
SINO    : 'else' ;
MIENTRAS: 'while' ;
 
/* ---------- Valores e identificadores ---------- */
// comillas rectas o tipográficas
TEXTO   : '"' ~["\r\n]* '"' | '\u201C' ~[\u201D\r\n]* '\u201D' ;
ENTERO  : [0-9]+ ;
NOTA    : [A-G] [0-8]? ;                  // se valida el rango (A0..C8) al ejecutar
PROC_ID : [A-Z] [a-zA-Z0-9_]* ;           // procedimientos: empiezan con mayúscula
VAR     : [a-z] [a-zA-Z0-9_]* ;           // variables: empiezan con minúscula
 
COMENTARIO : ( '###' .*? '###' | '~~~' .*? '~~~' ) -> skip ;
ESPACIOS   : [ \t\r\n]+ -> skip ;

Por qué importa el orden de las reglas
    • El lexer elige el patrón que reconoce más caracteres y, si empatan, el que se definió primero.
    • Por eso NOTA va antes que PROC_ID (la nota C8 empata con un nombre de procedimiento) y las palabras reservadas if, else y while van antes que VAR.
    • 8< es un solo símbolo (CORTA) y (:) y <:> son dos escrituras de la misma instrucción de tocar.
Paso 1.3  Escribe las reglas del parser
Ahora la estructura del programa. Estas reglas van al inicio del archivo, justo después de grammar Bazilio;:
Bazilio.g4 (parte del parser)
programa : procedimiento+ EOF ;
 
procedimiento : PROC_ID VAR* bloque ;
 
bloque : INICIO instruccion* FIN ;
 
instruccion
    : VAR ASIGNA expr                       # Asignacion
    | LEE VAR                               # Lectura
    | ESCRIBE (TEXTO | expr)*               # Escritura
    | TOCA expr                             # Reproduccion
    | PROC_ID expr*                         # Invocacion
    | SI expr bloque (SINO bloque)?         # Condicional
    | MIENTRAS expr bloque                  # Iteracion
    | VAR AGREGA expr                       # Agregado
    | CORTA VAR '[' expr ']'                # Corte
    ;
 
/* Prioridades como en C: índice > longitud > * / % > + - > relacionales > = /= */
expr
    : expr '[' expr ']'                                         # Indice
    | LONG expr                                                 # Longitud
    | expr op=(POR | ENTRE | MODULO) expr                       # MulDiv
    | expr op=(MAS | MENOS) expr                                # SumaResta
    | expr op=(MENOR | MAYOR | MENORIGUAL | MAYORIGUAL) expr    # Relacional
    | expr op=(IGUAL | DISTINTO) expr                           # Igualdad
    | '(' expr ')'                                              # Parentesis
    | '{' expr* '}'                                             # Lista
    | ENTERO                                                    # Entero
    | NOTA                                                      # Nota
    | VAR                                                       # Variable
    ;

Qué observar
    • Un programa es una lista de procedimientos; cada procedimiento tiene un nombre, parámetros opcionales y un bloque.
    • Las etiquetas # (Asignacion, Lectura, Escritura...) hacen que ANTLR genere un método visit para cada una; los usarás desde la etapa 2.
    • El orden de las alternativas de expr define la prioridad de los operadores, de mayor a menor, como en C.
    • La invocación PROC_ID expr* no lleva paréntesis ni comas: Hanoi (n - 1) ori aux dst.
Paso 1.4  Genera el lexer y el parser
Terminal
antlr4 -Dlanguage=Python3 -visitor Bazilio.g4

Se crean BazilioLexer.py, BazilioParser.py, BazilioVisitor.py y BazilioListener.py, además de algunos archivos .tokens e .interp. Mantén todos en la misma carpeta que tus programas de Python.
Paso 1.5  Escribe analizar.py
Este programa revisa la sintaxis y, si se lo pides, muestra los tokens o el árbol de sintaxis:
analizar.py
import sys
 
from antlr4 import CommonTokenStream, FileStream
from antlr4.error.ErrorListener import ErrorListener
 
from BazilioLexer import BazilioLexer
from BazilioParser import BazilioParser
from BazilioVisitor import BazilioVisitor
 
 
class ErrorBazilio(Exception):
    """Error de sintaxis o de ejecución de un programa Bazilio."""
 
 
class _ListenerErrores(ErrorListener):
    def syntaxError(self, recognizer, offendingSymbol, line, column, msg, e):
        raise ErrorBazilio(
            f"Error de sintaxis en la línea {line}, columna {column}: {msg}")
 
 
def parsear(flujo):
    lexer = BazilioLexer(flujo)
    lexer.removeErrorListeners()
    lexer.addErrorListener(_ListenerErrores())
    parser = BazilioParser(CommonTokenStream(lexer))
    parser.removeErrorListeners()
    parser.addErrorListener(_ListenerErrores())
    return parser.programa()
 
 
def nombre_token(lexer, tipo, texto):
    nombre = lexer.ruleNames[tipo - 1]
    # los símbolos sueltos ( [ ] { } ...) se muestran tal cual
    return texto if nombre.startswith("T__") else nombre
 
 
def listar_tokens(flujo):
    lexer = BazilioLexer(flujo)
    lexer.removeErrorListeners()
    lexer.addErrorListener(_ListenerErrores())
    tokens = CommonTokenStream(lexer)
    tokens.fill()
    return [(nombre_token(lexer, t.type, t.text), t.text)
            for t in tokens.tokens if t.type != -1]
 
 
def principal(argv):
    modo = "--revisar"
    if "--tokens" in argv:
        modo = "--tokens"
    elif "--arbol" in argv:
        modo = "--arbol"
    archivos = [a for a in argv[1:] if not a.startswith("--")]
    if not archivos:
        print("Uso: python3 analizar.py [--tokens | --arbol] programa.bzl "
              "[otro.bzl ...]")
        return 2
    estado = 0
    for ruta in archivos:
        try:
            if modo == "--tokens":
                for tipo, texto in listar_tokens(FileStream(ruta, encoding="utf-8")):
                    print(f"{tipo:<10} {texto}")
            elif modo == "--arbol":
                arbol = parsear(FileStream(ruta, encoding="utf-8"))
                print(arbol.toStringTree(ruleNames=BazilioParser.ruleNames))
            else:
                parsear(FileStream(ruta, encoding="utf-8"))
                print(f"{ruta}: sintaxis correcta")
        except ErrorBazilio as e:
            print(f"{ruta}: {e}")
            estado = 1
    return estado
 
 
if __name__ == "__main__":
    sys.exit(principal(sys.argv))

Paso 2.2  División como en C
El enunciado pide la prioridad de operadores de C. En C la división entera trunca hacia cero (−7 / 2 da −3), distinto de Python (−4):
bazilio.py
def _div_c(a, b):
    """División entera con truncamiento hacia cero, como en C."""
    q = abs(a) // abs(b)
    return q if (a < 0) == (b < 0) else -q

Paso 2.3  La clase Interprete y la pila de marcos
Cada invocación de un procedimiento tendrá sus propias variables. Aunque en esta etapa solo hay un marco, desde ahora las variables se guardan en una pila de diccionarios para que la etapa 4 sea solo agregar código:
bazilio.py
class Interprete(BazilioVisitor):
    def __init__(self, entrada=None, salida=None):
        self.marcos = [{}]            # pila de marcos (por ahora, uno solo)
        self._entrada = entrada if entrada is not None else sys.stdin
        self._tokens_entrada = []
        self._salida = salida if salida is not None else print
 
    @property
    def _vars(self):
        return self.marcos[-1]
 
    def ejecutar(self, arbol):
        for proc in arbol.procedimiento():
            if proc.PROC_ID().getText() == "Main":
                self.visit(proc.bloque())
                return
        raise ErrorBazilio("El programa no tiene un procedimiento Main.")

    • marcos[-1] es el diccionario de la invocación actual; _vars lo devuelve.
    • ejecutar busca el procedimiento Main y visita su bloque.
Paso 2.4  Instrucciones: bloque, asignación, lectura y escritura
dentro de la clase Interprete
    def visitBloque(self, ctx):
        for instruccion in ctx.instruccion():
            self.visit(instruccion)
 
    def visitAsignacion(self, ctx):
        self._vars[ctx.VAR().getText()] = self.visit(ctx.expr())
 
    def visitLectura(self, ctx):
        self._vars[ctx.VAR().getText()] = self._leer_entero()
 
    def visitEscritura(self, ctx):
        partes = []
        for hijo in list(ctx.getChildren())[1:]:               # el primero es <w>
            if hasattr(hijo, "symbol"):                        # es un TEXTO
                partes.append(hijo.getText()[1:-1])
            else:
                partes.append(self._formatear(self.visit(hijo)))
        self._salida(" ".join(partes))

    • visitEscritura recorre los hijos del nodo: los textos se escriben sin comillas y las expresiones se evalúan; todo se une con espacios en una sola línea.
Paso 2.5  Expresiones
dentro de la clase Interprete
    def visitEntero(self, ctx):
        return int(ctx.getText())
 
    def visitVariable(self, ctx):
        return self._vars.get(ctx.getText(), 0)                # sin valor todavía = 0
 
    def visitParentesis(self, ctx):
        return self.visit(ctx.expr())
 
    def visitMulDiv(self, ctx):
        a, b = self._operandos(ctx)
        op = ctx.op.text
        if op == "*":
            return a * b
        if b == 0:
            raise ErrorBazilio("División por cero.")
        q = _div_c(a, b)
        return q if op == "/" else a - b * q
 
    def visitSumaResta(self, ctx):
        a, b = self._operandos(ctx)
        return a + b if ctx.op.text == "+" else a - b
 
    def visitRelacional(self, ctx):
        a, b = self._operandos(ctx)
        return int({"<": a < b, ">": a > b, "<=": a <= b, ">=": a >= b}[ctx.op.text])
 
    def visitIgualdad(self, ctx):
        a, b = self.visit(ctx.expr(0)), self.visit(ctx.expr(1))
        return int((a == b) if ctx.op.text == "=" else (a != b))

    • Una variable sin valor vale 0, como pide la especificación.
    • Los relacionales devuelven 1 o 0; la división y el módulo por cero lanzan un error.
Paso 2.6  Utilidades
dentro de la clase Interprete
    @staticmethod
    def _entero(valor):
        if isinstance(valor, list):
            raise ErrorBazilio("Se esperaba un entero y se encontró una lista.")
        return valor
 
    def _operandos(self, ctx):
        izquierda = self._entero(self.visit(ctx.expr(0)))
        derecha = self._entero(self.visit(ctx.expr(1)))
        return izquierda, derecha
 
    @staticmethod
    def _formatear(valor):
        if isinstance(valor, list):
            return "[" + " ".join(str(x) for x in valor) + "]"
        return str(valor)
 
    def _leer_entero(self):
        while not self._tokens_entrada:
            linea = self._entrada.readline()
            if linea == "":
                raise ErrorBazilio(
                    "Se esperaba un entero en la entrada, pero ya no hay más datos.")
            self._tokens_entrada = linea.split()
        token = self._tokens_entrada.pop(0)
        try:
            return int(token)
        except ValueError:
            raise ErrorBazilio(
                f"Se esperaba un entero en la entrada y se leyó «{token}».")

    • _operandos evalúa los dos lados de un operador y comprueba que sean enteros; así las cuatro operaciones de la etapa no repiten esa lógica.
    • _formatear ya sabe escribir listas entre corchetes, aunque las listas se agregan hasta la etapa 5.

Etapa 3. Condicionales e iteración
Objetivo: que el intérprete tome decisiones y repita instrucciones. Es el mismo patrón que ya usaste en los intérpretes con if y while: se evalúa la condición y se visita el bloque correspondiente.
Paso 3.1  if / else y while
dentro de la clase Interprete
    def visitCondicional(self, ctx):
        bloques = ctx.bloque()
        if self._verdadero(self.visit(ctx.expr())):
            self.visit(bloques[0])
        elif len(bloques) > 1:                                  # el else es optativo
            self.visit(bloques[1])
 
    def visitIteracion(self, ctx):
        while self._verdadero(self.visit(ctx.expr())):
            self.visit(ctx.bloque())

    • ctx.bloque() devuelve la lista de bloques: el primero es el de if y el segundo, si existe, el de else.
    • while vuelve a evaluar la condición en cada vuelta.
Paso 3.2  Cuándo una condición es verdadera
dentro de la clase Interprete
    @staticmethod
    def _verdadero(valor):
        if isinstance(valor, list):
            raise ErrorBazilio("Una condición debe ser un entero "
                               "(0 es falso, otro valor es verdadero).")
        return valor != 0

Cualquier entero distinto de 0 es verdadero. Una lista no puede ser una condición.

Etapa 4. Procedimientos y recursividad
Objetivo: invocar procedimientos con parámetros y permitir que se llamen a sí mismos. Aquí se aprovecha la pila de marcos que preparaste en la etapa 2: cada llamada apila un diccionario nuevo y lo quita al terminar.
Paso 4.1  Carga, llamada y marcos
Reemplaza el __init__ y el ejecutar de la etapa 2 por este código (el método _vars de la propiedad se queda como estaba):
dentro de la clase Interprete
    def __init__(self, entrada=None, salida=None):
        self.procedimientos = {}      # nombre -> (parámetros, bloque)
        self.marcos = []              # pila de variables: un diccionario por llamada
        self._entrada = entrada if entrada is not None else sys.stdin
        self._tokens_entrada = []
        self._salida = salida if salida is not None else print
 
    def cargar(self, arbol):
        for proc in arbol.procedimiento():
            nombre = proc.PROC_ID().getText()
            params = [v.getText() for v in proc.VAR()]
            if nombre in self.procedimientos:
                raise ErrorBazilio(
                    f"El procedimiento {nombre} está definido más de una vez.")
            if len(set(params)) != len(params):
                raise ErrorBazilio(f"El procedimiento {nombre} repite nombres "
                                   "de parámetros formales.")
            self.procedimientos[nombre] = (params, proc.bloque())
 
    def ejecutar(self, inicio="Main"):
        self._llamar(inicio, [])
 
    def _llamar(self, nombre, valores):
        if nombre not in self.procedimientos:
            raise ErrorBazilio(
                f"Se llamó al procedimiento {nombre}, que no está definido.")
        params, bloque = self.procedimientos[nombre]
        if len(params) != len(valores):
            raise ErrorBazilio(f"{nombre} espera {len(params)} parámetro(s) "
                               f"y recibió {len(valores)}.")
        # un marco nuevo por cada invocación
        self.marcos.append(dict(zip(params, valores)))
        try:
            self.visit(bloque)
        finally:
            # al terminar, el marco desaparece
            self.marcos.pop()
 
    def visitInvocacion(self, ctx):
        valores = [self.visit(e) for e in ctx.expr()]
        self._llamar(ctx.PROC_ID().getText(), valores)

    • cargar registra todos los procedimientos antes de ejecutar nada, por eso el orden en que se escriben no importa.
    • También detecta procedimientos repetidos y parámetros formales repetidos.
    • _llamar crea el marco con los parámetros y lo elimina en el bloque finally, aunque haya un error.
    • Las listas (etapa 5) se pasarán por referencia porque el marco guarda el mismo objeto.

Paso 5.1  Las notas como números
Las teclas blancas del piano van de A0 (= 0) a C8 (= 51). Las notas sin número (C, D, ..., B) son la octava 4, así que C = 23. Agrega esto antes de la clase Interprete:
bazilio.py, antes de la clase Interprete
# las teclas blancas del piano: A0 = 0, B0 = 1, C1 = 2 ... C8 = 51
NOTA_MIN, NOTA_MAX = 0, 51
_POSICION = {"C": 0, "D": 1, "E": 2, "F": 3, "G": 4, "A": 5, "B": 6}
 
 
def valor_nota(texto):
    """'C4' -> 23, 'C' -> 23 (Do central), 'A0' -> 0, 'C8' -> 51."""
    letra = texto[0]
    octava = int(texto[1]) if len(texto) == 2 else 4
    if octava == 0:
        if letra not in "AB":
            raise ErrorBazilio(f"La nota {texto} no existe en el piano "
                               "(la octava 0 solo tiene A0 y B0).")
        return 0 if letra == "A" else 1
    valor = 2 + 7 * (octava - 1) + _POSICION[letra]
    if valor > NOTA_MAX:
        raise ErrorBazilio(
            f"La nota {texto} no existe en el piano (la última es C8).")
    return valor

Paso 5.3  Notas y listas en el intérprete
dentro de la clase Interprete
    def visitNota(self, ctx):
        return valor_nota(ctx.getText())
 
    def visitLista(self, ctx):
        elementos = [self.visit(e) for e in ctx.expr()]
        if any(isinstance(e, list) for e in elementos):
            raise ErrorBazilio("Las listas solo pueden contener enteros o notas.")
        return elementos
 
    def visitLongitud(self, ctx):
        valor = self.visit(ctx.expr())
        if not isinstance(valor, list):
            raise ErrorBazilio("El operador # solo se puede aplicar a una lista.")
        return len(valor)
 
    def visitIndice(self, ctx):
        base = self.visit(ctx.expr(0))
        if not isinstance(base, list):
            raise ErrorBazilio("Solo se puede consultar un índice en una lista.")
        i = self._entero(self.visit(ctx.expr(1)))
        self._comprobar_indice(ctx.expr(0).getText(), base, i)
        return base[i - 1]                # los índices empiezan en 1
 
    def visitAgregado(self, ctx):
        nombre = ctx.VAR().getText()
        lista = self._vars.get(nombre, 0)
        if not isinstance(lista, list):
            raise ErrorBazilio(f"{nombre} no es una lista: "
                               "no se puede usar << con ella.")
        valor = self.visit(ctx.expr())
        if isinstance(valor, list):
            raise ErrorBazilio("Las listas solo pueden contener enteros o notas.")
        lista.append(valor)
 
    def visitCorte(self, ctx):
        nombre = ctx.VAR().getText()
        lista = self._vars.get(nombre, 0)
        if not isinstance(lista, list):
            raise ErrorBazilio(f"{nombre} no es una lista: "
                               "no se puede usar 8< con ella.")
        i = self._entero(self.visit(ctx.expr()))
        self._comprobar_indice(nombre, lista, i)
        del lista[i - 1]
 
    @staticmethod
    def _comprobar_indice(nombre, lista, i):
        n = len(lista)
        if not 1 <= i <= n:
            raise ErrorBazilio(
                f"Índice {i} inexistente en {nombre} (la lista tiene {n} "
                f"elemento(s); los índices van de 1 a {n}).")

    • Los índices empiezan en 1: l[i] devuelve base[i - 1].
    • Un índice fuera de 1 a #l lanza un error con un mensaje claro.
    • l << x modifica la lista en sitio; 8< l[i] elimina el elemento i.

Paso 6.4  De un valor a LilyPond y a los archivos
Estas funciones van fuera de la clase. nota_a_lilypond convierte un valor en la notación absoluta de LilyPond (el Do central es c', el A0 es a,,,). generar_salida escribe el .ly y llama, en orden, a lilypond, timidity y ffmpeg:
bazilio.py, fuera de la clase
def nota_a_lilypond(valor):
    """Valor 0..51 -> LilyPond absoluto, duración de negra (p. ej. c'4)."""
    if not NOTA_MIN <= valor <= NOTA_MAX:
        raise ErrorBazilio(
            f"Se intentó tocar el valor {valor}, fuera del rango del piano (0 a 51).")
    if valor < 2:
        letra, octava = ("a", "b")[valor], 0
    else:
        k = valor - 2
        octava, letra = 1 + k // 7, "cdefgab"[k % 7]
    marcas = "'" * (octava - 3) if octava > 3 else "," * (3 - octava)
    return f"{letra}{marcas}4"
 
 
def version_lilypond():
    try:
        salida = subprocess.run(["lilypond", "--version"],
                                capture_output=True, text=True).stdout
        return re.search(r"(\d+\.\d+\.\d+)", salida).group(1)
    except (OSError, AttributeError):
        return "2.20.0"
 
 
def texto_lilypond(partitura, tempo=120):
    notas = [nota_a_lilypond(v) for v in partitura]
    renglones = [" ".join(notas[i:i + 8]) for i in range(0, len(notas), 8)]
    cuerpo = "\n".join("      " + r for r in renglones)
    return (f'\\version "{version_lilypond()}"\n'
            "\\score {\n"
            "  \\absolute {\n"
            f"    \\tempo 4 = {tempo}\n"
            f"{cuerpo}\n"
            "  }\n"
            "  \\layout { }\n"
            "  \\midi { }\n"
            "}\n")
 
 
def generar_salida(partitura, base, solo_ly=False, aviso=print):
    """Escribe base.ly y convierte con las herramientas externas que haya instaladas."""
    ruta_ly = base + ".ly"
    with open(ruta_ly, "w", encoding="utf-8") as f:
        f.write(texto_lilypond(partitura))
    generados = [ruta_ly]
    if solo_ly:
        return generados
 
    def correr(cmd, descripcion):
        if shutil.which(cmd[0]) is None:
            aviso(f"Aviso: no se encontró «{cmd[0]}», no se generó {descripcion}.")
            return False
        r = subprocess.run(cmd, capture_output=True, text=True)
        if r.returncode != 0:
            detalle = r.stderr.strip()[-400:]
            aviso(f"Aviso: falló {cmd[0]} al generar {descripcion}:\n{detalle}")
            return False
        return True
 
    # cada paso necesita el archivo del anterior: si uno falla, se detiene la cadena
    pasos = [
        (["lilypond", "-o", base, ruta_ly], "el PDF y el MIDI", [".pdf", ".midi"]),
        (["timidity", "-Ow", "-o", base + ".wav", base + ".midi"], "el WAV", [".wav"]),
        (["ffmpeg", "-y", "-loglevel", "error", "-i", base + ".wav",
          "-codec:a", "libmp3lame", "-qscale:a", "2", base + ".mp3"],
         "el MP3", [".mp3"]),
    ]
    for cmd, descripcion, extensiones in pasos:
        if not correr(cmd, descripcion):
            break
        generados += [base + e for e in extensiones]
    return generados

    • Todas las notas duran una negra y el tempo es negra = 120.
    • Si falta una herramienta, el intérprete avisa y sigue con lo que sí pueda generar.
Paso 6.5  Línea de comandos final
La función principal ahora genera los archivos si el programa tocó notas. Además, el programa se ejecuta en un hilo con una pila grande, para que la recursividad profunda no falle:
al final de bazilio.py
def principal(argv):
    solo_ly = "--solo-ly" in argv
    args = [a for a in argv[1:] if not a.startswith("--")]
    if not args:
        print("Uso: python3 bazilio_etapa6.py programa.bzl [Procedimiento] [--solo-ly]")
        return 2
    ruta = args[0]
    inicio = args[1] if len(args) > 1 else "Main"
    try:
        arbol = parsear(FileStream(ruta, encoding="utf-8"))
        interprete = Interprete()
        interprete.cargar(arbol)
        interprete.ejecutar(inicio)
        if interprete.partitura:
            base = os.path.splitext(ruta)[0]
            archivos = generar_salida(interprete.partitura, base, solo_ly=solo_ly)
            nombres = ", ".join(os.path.basename(a) for a in archivos)
            print("Archivos generados: " + nombres, file=sys.stderr)
    except ErrorBazilio as e:
        print(f"Error: {e}", file=sys.stderr)
        return 1
    except BrokenPipeError:
        return 0
    return 0
 
 
if __name__ == "__main__":
    sys.setrecursionlimit(200000)
    threading.stack_size(512 * 1024 * 1024)            # para recursividad profunda
    resultado = []
    hilo = threading.Thread(target=lambda: resultado.append(principal(sys.argv)))
    hilo.start()
    hilo.join()
    sys.exit(resultado[0] if resultado else 1)
